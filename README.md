# Mint Snake

Arcade snake for [Sullen Studio](https://github.com/SullenStudio). Dark mint grid, four chaotic snacks, combo burst every third bite.

Built with [Kaplay](https://kaplayjs.com). Visual vibe referenced from Dribbble/Behance (we drew our own shapes — no ripped assets).

## Play

```bash
npm install
npm run dev
```

- **Move:** arrows / WASD / swipe
- **Apple** — grow
- **Volt** — speed 4s
- **Pepper** — wrap through walls 2s
- **Bone** — shrink 2 segments
- Best score stays in `localStorage`

## Build

```bash
npm run build
```

Static files land in `dist/` (GitHub Pages friendly, `base: ./`).
